
## ☕ Coffee Shop Sales Analysis (Excel Project)

# 📌 Project Overview
This project focuses on analyzing coffee shop retail sales data using **Microsoft Excel** to uncover meaningful insights that help improve business performance.  
The analysis highlights sales trends, customer behavior, and product performance through interactive dashboards and visualizations.

---

# 🎯 Objectives
- Analyze sales patterns by **day of the week** and **hour of the day**
- Identify **peak sales hours**
- Calculate **monthly total revenue**
- Compare sales performance across **different store locations**
- Determine **average order value per customer**
- Identify **best-selling products** by quantity and revenue
- Analyze sales by **product category and type**

---

## 🛠 Tools & Techniques Used
- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Functions (SUM, AVERAGE, IF, COUNTIFS, etc.)
- Data Cleaning & Formatting
- Interactive Dashboard Design

---

## 📊 Key Insights
- Peak sales occur during **morning and evening hours**
- Certain store locations consistently outperform others
- A small set of products contributes to the majority of revenue
- Weekends generate higher average order values compared to weekdays
